## 实现

保留正式半身立绘、大号单行时间、`MM/DD`月日和电量，不显示独立Logo、步数、星期或秒。按屏高等比缩放人物，按设备真实调色板生成资源；不同14色调色板分开存储。时间和底栏按实际字体度量与圆屏边界排布。
